Website Project

For this assignment, I created a personal HTML website that acts as a main hub for multiple websites and projects I created throughout the course. Using HTML code, I designed the site to function as a homepage where users can navigate to my other projects by clicking on images and graphics connected through links. Each project had its own separate folder and index.html file, so I used code within the main website’s index.html to link everything together and organize the layout the way I wanted. I also experimented with positioning elements across the page to create a design that felt personal and visually engaging.

The overall aesthetic of the website was inspired by digital and internet culture, which is why I used a Matrix-style background filled with green binary numbers along with GIFs, images, and digital-themed graphics. I included personal details about myself on the homepage to make the site feel more interactive and connected to my personality and interests. I also used graphics representing different projects, such as my CSS Landscape website, Net Art project, and other assignments, allowing visitors to easily explore each section of the site.

One of the main things I learned from this project was how HTML websites can connect multiple pages together through linking and file structure organization. I also gained more experience working with image placement, page layouts, and combining visuals with code to create a functioning and creative web experience. This assignment helped me better understand how websites are structured behind the scenes while also giving me the freedom to create something that reflected my own style and interests.
